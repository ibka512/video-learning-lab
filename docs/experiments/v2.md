# 通用知识抽取 v2 实测报告

核对日期：2026-10-29。

## 交付结果

已实现证据来源记录、主题规划、概念与操作字段、联合语音/OCR证据包、原文位置校验、辅助内容判断、有限重试、源复核和按领域导出。当前交付的是按对象与知识类型组织的原文知识稿，仍需 Codex 复核；没有实现无人复核的完整视频学习。

- 前端组件知识稿（本地证据未公开）：7 个组件，20 个复核后字段。
- Godot 局部知识稿（本地证据未公开）：4 个新字段，另保留旧版8条设置/帮助/单帧状态记录。完整操作步骤未通过验收。

18 项检查的是预先列出内容在正确对象、时间和允许字段中的措辞保留，结合 Codex 的逐项源复核；不是独立人工语义准确率。部分定义块包含整章的场景和建议，尚未精炼为最小原子事实。

模型曾将 Empty 的标题放在相邻语句中。具体错误反馈提供原句与精确匹配位置后，第二次规划修正。该错误与修正没有删除。

Collapse 的两次抽取均产生完全重复的字段。程序只删除相同类型与相同引用序列的重复项，恢复6个候选，不改写、补充或重新分类内容。该步骤不算模型原始输出通过检查。

Carousel 的主题边界漏掉 S0036 的“超过五张”提醒。覆盖层对两个主题之间以“注意/不要/不能/避免/切勿”起始的语句，生成暂归前一主题的限制候选。本片新增1条候选，源复核确认归属后才导出。这是明确记录的程序规则，不是模型自动找到该经验；其他边界遗漏仍可能发生。

## 辅助模型不能替代源复核

辅助模型检查了26个字段：18项 supported、6项 unsupported、2项 uncertain。Codex 最终拒绝了其中5项被辅助模型认为 supported 的候选。例如把比喻或使用场景当成组件比较、把场景说明当成限制。

复核也允许在理由明确的情况下与模型判断不同：有些完整原句块确实解释了定义，但同时包含额外场景；本版允许其作为较宽的定义证据块，报告不会把它称作最小原子事实。这些分歧说明需要人工校准评估标准，不能用同一小模型的自我检查宣称自动正确率。

## Godot 教程

原先的模型规划两次未能提供可精确定位的“窗口设置”标题。增加标题枚举的试跑仍出现重复主题与 overflow。相关失败位于 r3/r4，均未作为成功成绩。

最终版本对没有明确序数章节的材料保留一个 reference 源容器，标题采用实际原句；这不是模型自动理解出任务边界。容器内仍由模型分类知识。

两次字段抽取分别出现重复输出和漏记片头 SC0000。程序删除完全重复项，并把未分类语句显式留作 insufficient_context，不为它补造知识。最终恢复9个候选；Codex 复核通过4项，拒绝5项。

最重要的失败是操作步骤：模型的步骤组止于 SC0009，漏掉完成该分支所需的 SC0010“再重新启动场景即可”。因此正式稿不导出该步骤组，操作类知识的质量验收仍未通过。部分条件和补救说明在另一个完整原句块中保留，不等于已形成合格的顺序步骤。

旧版8条设置、帮助与单帧状态记录逐项保持一致。默认值没有被升级为当前状态，作者口述也没有被升级为实际观察。本轮没有新增逐帧视觉理解。

最终Godot字段阶段记录2次模型调用，耗时合计76.60秒；两个输出均未直接通过完整性检查，9个候选来自显式输出恢复，不能算成2次成功抽取。恢复后未重新运行辅助判断，直接进行Codex源复核。

## 与上一轮相比

上一轮前端视频只有48段转写附录，结构化组件对象0/7。本轮模型能规划7个组件，并形成按定义、场景、交互、限制和比较组织的候选；结合程序恢复和源复核，得到7个组件的可追溯知识稿。

仍需解决：小模型重复输出、分类混杂、主题边界丢失经验、长操作步骤不完整，以及较宽定义块和重复OCR导致的冗余。逐帧动作理解、主动补看、长视频分层规划、跨视频关系和收藏夹批处理未实现。本轮不能据此进入全量收藏夹自动发布。

下一步优先将操作过程拆成有前提、动作和结果的独立步骤，加入遗漏步骤检查，再用另一条未参与调试的教程验证。概念稿的精炼与操作步骤完整性都应继续单独评分。
