# 下一轮任务

## 当前优先级：窗口身份证据实验

沿用已有模型，冻结新的窗口证据目标后再推理。

1. 独立读取标题文字、独立标题栏、窗口边界及前后层次，不把整个编辑器截图直接压成一个类别。
2. 用相同画面和提示单独比较分辨率，记录实际缩放尺寸；随后再单独比较目标区域与全图上下文。
3. 保留原始读数、对象关系候选与冲突，不凭标题中的一个词自动核准窗口类型。
4. 分别评价线索是否读到、线索归属是否正确、窗口类型是否正确，统计漏项、不确定和成本。
5. 与v6冻结材料比较，再决定是否需要更强模型。新增权重、服务或重要依赖由维护者决定。

## 随后推进

- 状态、讲解要求、动作、结果的关系绑定。
- 宽上下文中的最小事实跨度、共享条件和跨类别去重。
- 稳定流程后的新视频与实际应用验证。
- 连续片段和长视频，最后再做收藏夹批处理。

## 完成口径

工程检查通过和语义收益分别验收。不能通过全部拒答制造低错误率；应同时报告有效输出覆盖。新样本一旦用于修改流程，就转为开发样本。
