# PaddleOCR 局部复核接入实测

日期：2026-10-28。对象：BV1cyHR67EbJ，68.83 秒、1920×1080、30 FPS，2065 帧。目标是让既有视频知识流程获得可追溯的关键文字补充证据。

## 结论与范围

PaddleOCR 局部复核已接入：自动选区、识别缓存、实际帧/时间/坐标、两引擎冲突和知识输入均已贯通。修正选区后，61 个关键文字目标中严格匹配 59 个，完整目标含在输出中的有 60 个。仍有一个 false 被识别成 fal.se，不能把 OCR 输出直接当成正确知识。

本轮复用了原有全部 2065 帧的 Apple Vision 记录，另选 69 个每秒代表帧，并加入 24 个固定回归帧，去重后共 85 帧。Paddle 实际读取 388 种不同区域、426 个按帧定位的区域实例，83 帧产生了文字。其余代表帧没有触发区域。这不是 Paddle 全片逐帧识别，也没有重新运行整片语音和视觉模型。

## 实现

1. 初始 OCR 中的路径、文件名、复合名称、数值、帮助说明和菜单控制词触发局部复核，高置信度文字也可触发。
2. v1 发现漏掉无扩展名的名称、裁掉相邻菜单行后，v2 增加通用复合名称规则，并保留相邻行的完整边界。没有按本视频名称硬编码答案。
3. 仅对尺寸和 RGB 像素完全相同的区域复用结果。每次实际出现仍保留独立帧、时间和位置，不推断中间连续状态。
4. 原始 OCR 不覆盖。Paddle 和 Apple 的不同读数、原图、裁剪图、模型配置和校验值全部保留。文字相同也不自动标为事实正确。
5. 补充证据送入现有知识生成器；所有候选默认未复核，不进入已确认知识。

## 文字回归成绩

使用此前逐项对照源图建立的同一组 69 个目标。严格匹配只忽略空白和 Unicode 标准等价形式，大小写、下划线、斜杠和标点都必须相同。

| 条件 | 关键文字严格匹配 / 61 | 全部目标严格匹配 / 69 |
|---|---:|---:|
| 原 Apple Vision 整帧 | 21 | 25 |
| Paddle 先前人工裁剪对照 | 60 | 67 |
| 自动局部选区 v1 | 53 | 54 |
| 自动局部选区 v2 | 59 | 64 |

v2 的配置键含转场为 11/11，菜单文字 24/24，帮助标题 8/9，资源名含转场 14/15，窗口标题 2/2。11 次配置键观测来自 3 个不同键，不能当作 11 个独立案例。全部 69 个目标中还有普通字幕、节点名和效果文字，它们并非该模块的必选类别。

关键目标的两处严格失败：

- F0000090，3.00 秒：`res://Meta/ColorBG3.png` 前多了界面符号 `( >`。完整路径在识别输出中，但严格整行匹配失败。
- F0000390，13.00 秒：帮助标题中的 `false` 被识别为 `fal.se`。这是识别错误，不能自动作为参数写进知识。

v2 是看到 v1 漏项后修正规则得到的回归结果，不是独立留出集成绩。这 24 帧来自同一视频且存在重复内容，不能外推为所有收藏视频的准确率。

## 知识生成与验证结论

41 个源区间的 61 个输入包已经准备，3156 条新证据全部进入对应区间。实际推理仅验证了 SC0004 一个区间，约 82.54 秒，模型生成 3 条候选；虽然输入包含 98 条新 OCR，3 条都没有引用新证据，并出现帮助对象混淆、句尾遗漏和来源类型错误。已逐项标为不可导出，见 知识候选复核（本地证据未公开）。

提供了一个单独标注为 Codex 源图复核的领域 Markdown 示例，不将其当作自动生成通过。全片知识生成没有重跑，收藏夹没有开始批处理。

工程验证：10 项针对选区、坐标和时间边界的测试通过；388 份当前区域回执、471 张被引用图片、3156 条证据的来源/坐标/时间与 61 个输入包检查通过，原始 Apple OCR 校验值不变。缓存恢复全部命中且回执不变。详见 检查结果（本地证据未公开） 与 测试记录（本地证据未公开）。先前两轮结果 ZIP 的校验值也保持不变。

当前仍存在初始 OCR 未发现文字时无法触发复核、每秒补充取样可能错过短暂变化、OCR 错字和语义整理不可靠等限制。OCR 模块可继续用于补充证据；完整自动学习与批量知识导出还没有达到验收条件。
