# 逐帧证据验证 v5 实测报告

日期：2026-10-29。本轮范围为统一观察记录、单图/多图对照、程序一致性检查、模板描述及有上限的定向回看。仍使用已有 Godot 开发样本。

## 主要结论

工程流程已完成，但整体准确率提升未通过验收。单图读取优于本轮多图状态记录；基于重复一致的回看会放大错误，因此不作为默认修复，不替换现有知识生产路线。

仅视觉条件下，B 原始状态正确 15/24，C 为 18/24。经过结构和对象一致性检查后，B 为 11/24，C 为 17/24。D 回看后仅 16/24，确定错误由 C 的 5 个增加至 8 个。

原 v4 仅视觉选项题15/18，B/C/D 三个仅视觉流程对应旧题均10/18。新流程还增加了逐帧与对象一致性约束，不能把差值直接当成纯感知退步；但当前整体结果没有理由替换旧路线。B 转写加图及反转的双向兼容成绩也未达到旧基线。

主要剩余问题包括：前景窗口与背景编辑器混淆；模型看到内容却把状态归给错误对象；蓝色圆形与碎片等共存信息被单一主状态标签压缩；补读复制搜索区域作为对象框；同一模型跨视图一致看错。不能把这些问题全部归因于模型规模。

## 交付状态

已实现并运行上述流程。原始模型输出、程序推导、源参考、回看决策分别保存，候选知识未自动升级为正式知识。没有新增模型、生产依赖或外部付费服务。

## 对照与工程修正

- A：复用 v4 原始成绩与回执，不覆盖、不重跑。
- B：四图联合读取，输出逐位置对象/状态，再由程序生成答案与描述；运行视觉、转写加视觉、反转加原转写三种条件。
- C：逐张独立读取相同24个位置，无转写；与 B 使用相同模型、像素预算和重复单帧的时序编码。单图不是新增模型。
- D：以 C 为基础，使用 B 视觉结果发现分歧；针对不确定、内部冲突或分歧补读整张原图，再按初始对象区域补读局部。最多两轮/帧、48次总补读。
- D 中两次观察一致仅标为候选得到重复支持，不等于语义核准。无新视图、达到上限或仍有分歧时保留不确定。
- 本轮导出只允许状态及采样间变化，不生成操作完成断言。避免“已经取消”来自输出范围约束，不代表已解决动作识别。菜单题从状态推导static_checked的收益也不能算新增视觉识别能力。

首次诊断 r1 完成 23 次调用后停止：56 条原始观察中，51 条把确定状态和不确定理由组合；8 次调用引用不存在的对象。用这些数据继续补读会大量消耗请求。r1 的原始结果和代码已保留，不能当成完成的 A/B/C/D 对照。

随后在 r2 推理前冻结修订协议：确定与不确定记录采用互斥结构，确定状态必须有第一项目标对象、reason=none；不确定状态必须给出原因。该改进是程序约束生成，不应称为模型自主学会自我检查。原始样本、参考答案和回看策略未改。

r2 完成全部42次基础对照后，在补读中发现原图像素坐标与输出归一化坐标混用，模型把1805照抄/截成180，导致区域无效。保留 14 次补读诊断回执（其中 8 次格式失败），修订为相对当前输入画面的0–1000坐标。r3 只重跑受影响的 D，42次 B/C 原始结果逐字复用并绑定哈希，没有再运行。

## 回看效果

共有 12 个位置触发回看。C 的 5 个确定错误中，3 个被触发器覆盖；另有 2 个不确定位置，其中 2 个进入补读。

补读后 12 个位置得到重复支持，0 个仍不确定；重复支持结果中仍有 6 个错误。C→D：错误变正确 0 个，错误转不确定 0 个，原本正确转不确定 0 个，原本正确变错误 1 个。

分歧检测不能发现模型在不同调用中一致看错的情况。第二轮区域来自初始模型的对象框，框过宽或框错会限制精读收益。全图补读增加了背景、外围字幕等上下文，因此不是纯分辨率实验。

源复核例证：T-1 的原始单图状态正确识别为 Godot 启动画面，但对象种类/层次不匹配而被拦下；两次补读随后都改成错误的编辑器预览。C-2 原本正确的碎片状态也被两次一致补读改成完整背景。C-3 的原始线索已经提到“蓝色圆形与白色碎片共存”，主状态却选碎片，说明需要保存对象级并存属性。复核仅作诊断，没有反写模型成绩。

## 本轮边界与后续

本轮完成所批准的第一阶段实验闭环。尚未完成声画关系自动绑定、最小事实跨度/跨类别去重、独立新视频、连续动作定位、正式知识自动发布或收藏夹批处理。本轮没有重新进行实际 Godot 软件应用测试。

后续优先将窗口身份、运行内容、勾选状态分为对象级属性，并允许圆形/碎片等共存；缩小单次模型需要填写的任务；回看结果只追加证据，不因同模型一致就覆盖已有状态。再独立比较单图原生图像编码、目标区域输入与当前时序单帧编码，避免把表示方式问题误认为模型容量不足。必要时才做同材料的更强模型对照。上述属于下一轮设计建议，本轮未新增实现。
