## 判断

当前保留的处理顺序是：全帧时序输入与完整原始文字留存 → 声音/画面/帮助文字分别记录 → 精确参数回原图局部核对 → 冲突进入复核 → 已复核知识导出 → 全新上下文读取笔记并做应用验证。局部区域目前由 Codex 选取，自动选区尚未实现；不是所有步骤都能无人参与执行。

已证明有效的改动包括：来源可追踪、完整文字保留、三项长设置名的局部读出、两处 Godot 术语提示，以及把有问题的候选与已复核笔记分开。尚不能宣称软件状态误判、无人复核自动理解或全收藏效率已经解决。后续若评估更强模型，应复用本轮同源片段、原图和问题进行对照，再决定依赖、下载和算力。
